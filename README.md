### Getting Started
> After all dependencies are installed
1. Navigate to theme directory
2. run: yarn run setup
3. update seed.config.js with the proper store url
4. run seed cli commands to begin dev.

## SEED CLI Theme Commands
- seed watch  

  > No options  
  > Begin watching the /src folder for changes.  
  > A development theme will be generated by Shopify CLI for preview and customization (must be viewed in Chrome).  

- seed deploy [options]  

  > This will deploy the theme to specified environment (default 'development') with Shopify CLI push command (runs with --nodelete flag by default).  
  > --store <store> | deploys to matching store in seed.config.js (used with multistore config only)
  > --env <theme> | deploys to matching theme name in seed.config.js  
  > --skip-optimizations | does not run tailwind purge, minify css or minify js  
  > --delete | will delete all files not present in local files  
  > --no-dev | do not pull from dev environment, this will just push all files as they are in local without syncing with the developer's shopify development environment 

- seed pull [options]  

  > This will pull from specified environment (default 'development') to local with Shopify CLI pull command (runs with --nodelete flag by default). Will only pull and overwrite files in 'templates' folder
  > --store <store> | pulls from to matching store in seed.config.js (used with multistore config only)
  > --env <theme> | pulls to matching theme name in seed.config.js
  > --all | Overwrites files in all folders. Does not delete any local files
  > --delete | Deletes any local files that are not on the remote environment. Must also be run with --all flag.
